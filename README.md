# Learn-GitHub
Repo for Learning GitHub. </br> </br>


- To Check If Git Is Installed Or Not : It will show the git version if present
```
git --version
```
</br> </br>

- To Setup Your GitHub With Name & Email :
```
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
```
</br> </br>

- To see your current Git configuration :
```
git config --global user.name
git config --global user.email
```
</br> </br>

- To Initialize Git Repository :
```
git init
```
</br> </br>

- To Stage ALL files in the current directory for commit :
```
git add .
```
</br> </br>

- To see Which files are staged (ready to commit) - in GREEN, Which files are modified but not staged - in RED & Which files are untracked (new files Git doesn't know about) :
```
git status
```
</br> </br>


git clone [repo url HTTP] : to get code repo in our system
